Vitrina

An apt repository for Debian, Ubuntu and their derivatives. It carries the latest release of each app below, for amd64 and, where the app ships one, arm64.

Add the repository

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://vitrina-project.dev/vitrina.asc | sudo tee /etc/apt/keyrings/vitrina.asc > /dev/null
sudo tee /etc/apt/sources.list.d/vitrina.sources > /dev/null <<'EOF'
Types: deb
URIs: https://vitrina-project.dev/apt
Suites: stable
Components: main
Architectures: amd64 arm64
Signed-By: /etc/apt/keyrings/vitrina.asc
EOF
sudo apt update

Install an app

sudo apt install editora

After that, sudo apt upgrade keeps it up to date.
